🎓 Smart Student Dashboard (DAKSHA)

A all-in-one web dashboard for students that brings everyday study tools into one place. Sign up, log in, and use handy tools like a calculator, to-do list, whiteboard, PDF converter and an AI chatbot, all from a single clean interface.



✨ Features
🔐 Login / Sign Up – user authentication to access the dashboard
🧮 Calculator – quick calculations without leaving the dashboard
✅ To-Do List (TrackIt) – add, track and complete your daily tasks
🖍️ Whiteboard – draw with brush, shapes (circle, rectangle, triangle) and eraser
📄 PDF Converter – convert files to PDF and PDF to images
🤖 AI ChatBot – ask doubts and get instant answers
📚 Study Material – access study resources in one place
👤 Profile & Help pages for a complete user experience
🛠️ Tech Stack

Technology	Usage
HTML5	Structure of the pages
CSS3	Styling and responsive layout
JavaScript	Logic, authentication and tool functionality
